Formal State-Space Search & Complexity Analysis

1. Evaluation Functions

- Greedy Best-First Search: f(n) = h(n) expands the node that appears closest to the goal based on the Euclidean heuristic. It discards the cost incurred so far, creating vulnerability to costly detours.
- A* Search: f(n) = g(n) + h(n) combines exact historical path distance g(n) with estimated remaining cost h(n).

2. Heuristic Admissibility Proof

The Euclidean distance heuristic is computed as h(n) = sqrt((x_n - x_goal)^2 + (y_n - y_goal)^2).
- In 2D Euclidean space, the straight-line segment represents the minimal possible continuous distance between two coordinates.
- In our campus graph datasets, every edge weight satisfies w(u, v) >= EuclideanDistance(u, v).
- By the triangle inequality, for any path from node n to goal g, sum w(e) >= EuclideanDistance(n, g) = h(n).
Therefore, h(n) <= h*(n) everywhere, satisfying strict admissibility and monotonic consistency.

3. The Section 8 Misleading Trap

In misleading_map.json, node A = (1, 0) has h(A) = 1.0 to goal G = (2, 0), while node B = (0, 2) has h(B) = 2.83.
- Greedy is blinded by 1.0 < 2.83 and expands A, committing to the 100m edge with total cost 101.0m.
- A* evaluates f(G via A) = 1 + 100 + 0 = 101.0, pauses, and pops B from the priority queue because f(B) = 2 + 2.83 = 4.83 < 101.0, discovering the true optimal path S -> B -> G with total cost 5.0m!
