Section 8: The Misleading Heuristic Experiment Explained

In misleading_map.json, Node A has straight-line distance h(A) = 1.0m to Goal G, while Node B has h(B) = 2.83m.
Greedy Best-First Search greedily expands A because 1.0 < 2.83, committing to the 100m edge with total cost 101.0m.
A* Search evaluates f(G via A) = 1 + 100 = 101.0m, halts, pops B (f=2 + 2.83 = 4.83m < 101m), and finds the optimal path S ➔ B ➔ G with total cost 5.0m (demonstrating a +1920.0% excess cost in Greedy search).
